Program Description ​

This SAS script serves as the main execution wrapper for the WVS (WarenVersorgungsStatistik) - Goods Supply Statistics calculation process within the BDWH_SCCWVS application. The script is part of building a parallel environment to replace the legacy data warehouse system.

The file orchestrates the complete setup and execution flow by:

  • Loading global declarations and configuration files
  • Establishing connections to both legacy DWH and product SCC databases
  • Setting up WVS-specific configurations and format libraries
  • Executing the core calculation logic through sccwvs_020_wvs_berechnen_elab.sas

This script corresponds to the legacy job BDWH_ELVS_FEHLGRND.BDWH_DW017682 with minor modifications for the parallel environment setup. It's designed to be restartable in case of failures, with built-in error documentation for known abort scenarios.

The script follows a modular approach by including various declaration and configuration files, making it maintainable and allowing for environment-specific customizations while ensuring consistent database connections and global settings across the WVS processing pipeline.
