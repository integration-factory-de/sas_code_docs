Program Description ​

This SAS script is part of the BDWH_SCCWVS application and implements supplier determination logic for the WVS (WarenVersorgungsStatistik) - Goods Supply Statistics system. The script addresses the issue that the LIEF_ID field from the ELVS commissioning pool is only populated approximately 75% of the time.

The script employs a multi-stage hierarchical approach to determine missing suppliers for the remaining 25% of records:

  1. Stage K: Uses existing LIEF_ID from commissioning pool
  2. Stage X: Implements new WE procedure examining 0-4 days back
  3. Stage A: Retrieves from F_WA_EK with exact validity period (goods outbound)
  4. Stage E: Retrieves from F_LAG_EK with exact validity period (goods inbound)
  5. Stage S: Uses last valid supplier from F_LAG_EK as substitution
  6. Stage D: Assigns dummy values for remaining records

Each determination method is marked with a corresponding LIEF_KZ quality indicator (K, X, A, E, S, D) to track the source and reliability of the supplier assignment.

The script includes comprehensive data validation by comparing record counts before and after processing to ensure data integrity. It also performs cleanup operations to remove temporary datasets and maintains evaluation tables from preceding ELVS applications when available.
