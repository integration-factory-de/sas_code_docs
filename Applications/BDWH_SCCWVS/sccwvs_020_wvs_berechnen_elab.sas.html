Program Description ​

This SAS script is part of the BDWH_SCCWVS application and processes WVS (WarenVersorgungsStatistik) - Goods Supply Statistics data. The script builds a parallel environment to replace the legacy data warehouse system.

The main purpose is to perform line-by-line resolution of shortage quantities and values by reasons from the DWH.F_ELVS_FEHL_ART table, specifically handling data sourced from the new ELAB system (HERKUNFT_BASIS = 'ELAB') after ELVS core replacement.

Key Processing Steps:

  • Data Extraction: Retrieves order and delivery data from the last 21 days, filtering out cancelled orders and empty containers
  • Manual Table Creation: Establishes mapping tables for shortage reason codes (pos_kv_ursache and pos_fehler_schl)
  • Calculation Logic: Processes each position to create multiple records based on different shortage scenarios:
    • Header record with total order quantities (fehl_art_grund_id 1999990)
    • Over-deliveries when delivered quantity exceeds ordered quantity
    • Post-commissioning adjustments for follow-up deliveries
    • RMS-based quantity adjustments and reductions
    • Recorded shortage reasons from source systems
    • Global quantity reductions based on warehouse type
    • Unknown reasons for remaining shortage quantities

Technical Features:

  • Uses Snowflake database connections with configurable warehouse sizing
  • Implements hash objects for efficient lookup operations
  • Supports delta processing to handle large data volumes
  • Includes comprehensive error handling and restart capability

The script generates detailed shortage analysis records that feed into the goods supply statistics reporting system.

differenz = best_mg_orig - ers_lief_mg;
lag_typ_id=put(lagnr||put(kal_tag_id,z8.), lag_lagtyp.);
*1. Kopfsatz: In jedem Fall, auch wenn keine Fehlmengen vorliegen, wird ein Kopfsatz ausgegeben, der die
Bestellmenge - und -werte beinhaltet mit fehl_art_grund_id 1999990. ;
fehl_art_grund_id = 1999990;
fehl_grund_mg = 0;
fehl_grund_w_ek_bto = 0;
fehl_grund_w_wg_bto = 0;
fehl_grund_w_vk_bto = 0;
* bei Nachlieferung , d.h. lifart='25' und pos_nachlief_kz='J', wird die best_mg im Kopf auf 0 gesetzt, denn es ist keine echte Neubestellung,
sondern es gibt dazu einen Satz mit Best_mg > 0 und Fehl_mg . Diese best.mengen duerfen
nicht doppelt gezaehlt werden ;
if kopf_lifart='25' and POS_NACHLIEF_KZ = 'J' then do;
best_mg = 0;
best_w_ek_bto = 0;
best_w_wg_bto = 0;
best_w_vk_bto = 0;
end;
output;
* 2. Ueberlieferung ers_lief_mg > best_mg - mehr geliefert als bestellt
(aber nicht RMS, da gilt fmgrund 80, und nicht pos_kuerz_kst_kz, s.u.);
if differenz < 0 and pos_kv_ursache ne '80' then do;
fehl_art_grund_id = 1999991;
fehl_grund_mg = differenz;
%werte_setzen;
output;
end;
* 3. Nachkommissionierung;
if kopf_lifart='25' and pos_nachlief_kz = 'J' then do;
fehl_art_grund_id = 1003003;
fehl_grund_mg = - ers_lief_mg;
fehl_grund_w_ek_bto = - ers_lief_w_ek_bto;
fehl_grund_w_wg_bto = - ers_lief_w_wg_bto;
fehl_grund_w_vk_bto = - ers_lief_w_vk_bto;
best_mg = 0;
best_w_ek_bto = 0;
best_w_wg_bto = 0;
best_w_vk_bto = 0;
output;
end;
* 4. Kuerzungen oder Erhoehungen aufgrund RMS, da gilt fmgrund 80;
* pos_kuerz_kst_kz ist aus kundenauftragaenderung, Feld DIFFVERTEILUNGKZ='KUERZUNG' abgeleitet;
* pos_diffmng bisher immer negativ, sollte aber auch f >0 funktionieren;
if differenz ne 0 and pos_diffmng ne 0 and (pos_kv_ursache = '80' or pos_kuerz_kst_kz='K') then do;
fehl_art_grund_id= 1101080;
differenz=differenz + (pos_diffmng*pos_waeinh);* differenz neu berechnen f evtl weitere fehlmg;
fehl_grund_mg = -(pos_diffmng*pos_waeinh);
%werte_setzen;
output;
end;
* fuer den Kuerzungs-Grund wurde differenz neu berechnet. Wenn jetzt immer
noch eine Differenz uebrig ist, kommt fuer den Rest ein weiterer Fehlgrund hinzu;
* 5. erfasste Fehlmengen-Gruende aus pos_kv_ursache (Quellsystem: fmgrund) oder pos_fehler_schl;
if differenz > 0 and fehl_art_grund_id_ ne . and pos_kv_ursache ne '80' then do;
fehl_art_grund_id = fehl_art_grund_id_;
fehl_grund_mg = differenz;
%werte_setzen;
differenz = 0;
output;
end;
* 6. Kuerzungen (aber nicht RMS, da gilt fmgrund 80, und nicht pos_kuerz_kst_kz, s.u.)
dieser Abschnitt greift nur, wenn vorher kein FS/KVGRUND zugeordnete werden konnte;
if differenz ne 0 and pos_kuerz_global_kz='K' and pos_kv_ursache ne '80' and pos_kuerz_kst_kz ne 'K' then do;
* Unterscheidung nach Lagertyp und wg2 ;
if (lag_typ_id eq '1O' and wg_2_id not in (116,117,118))
or lag_typ_id not in ('1O') then fehl_art_grund_id = 1003106; * Mengenkürzung aufgrund Disposition;
else
if lag_typ_id='1O' and wg_2_id in (116,117,118) then fehl_art_grund_id = 1003104; * Mengenkürzung O+G ;
if akt_kz='A' then do;
differenz = differenz - kuerz_mg_aktion; * differenz neu berechnen f evtl weitere fehlmg;
fehl_grund_mg = kuerz_mg_aktion;
end;
else do;
differenz = differenz - kuerz_mg; * differenz neu berechnen f evtl weitere fehlmg;
fehl_grund_mg = kuerz_mg;
end;
%werte_setzen;
output;
end;
* 7. unbekannter Grund / Restfehlmenge;
if differenz > 0 and fehl_art_grund_id_ = . then do;
* Unterscheidung nach Lagertyp und wg2 ;
if (lag_typ_id eq '1O' and wg_2_id not in (116,117,118))
or lag_typ_id not in ('1O') then fehl_art_grund_id = 1000002; *Fehlmenge im Lager aufgrund Disposition ;
else
if lag_typ_id='1O' and wg_2_id in (116,117,118) then fehl_art_grund_id = 1000001; *Fehlmenge im Lager O+G ;
fehl_grund_mg = differenz;
%werte_setzen;
output;
end;
run;
