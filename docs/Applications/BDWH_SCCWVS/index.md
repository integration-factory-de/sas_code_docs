## Application Description

**BDWH_SCCWVS** is a **Waren-Versorgungs-Statistik (WVS)** application that builds a parallel environment to the legacy data warehouse for supply chain analytics and reporting.

This application processes and analyzes **goods supply statistics** by calculating shortage reasons, supplier identification, and delivery tracking across retail locations. The system handles data from **ELAB** (post-ELVS core replacement) sources and processes commission pool data, delivery tracking, and inventory management information.

**Key functionalities** include:
- **Delivery date determination** from tracking data over the last 28 days
- **WVS calculation** with detailed shortage reason analysis and supplier assignment
- **Supplier identification** through multi-stage processes using purchase price tables
- **Relevance marking** for WVS-relevant records with delivery date changes and quantity adjustments
- **Data aggregation** at various levels (daily, weekly, regional)
- **Staging and data warehouse integration** with cleanup processes

The application runs **daily calculations** covering the last 21 days retrospectively, ensuring data accuracy and enabling **supply chain performance monitoring** and **shortage analysis** for retail operations. It supports both regular articles and promotional items, with special handling for bill-of-materials relationships and action week deliveries.
